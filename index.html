JavaScript Operators and Conditions

Simple explanation for beginners.

1. Arithmetic Operators

Used for math.

Operators: + - * / %

let price = 100; let tax = 20; let total = price + tax; console.log(total);

Example: Shopping bill.

Task: Create two numbers and multiply them.

2. Assignment Operators

Used to store values.

= += -=

let score = 10; score += 5; console.log(score);

Result becomes 15.

Task: Create a variable called money and add 50 to it.

3. Comparison Operators

Used to compare values.

== === != > < >= <=

Difference between == and ===

== checks value only.

=== checks value and type.

console.log(5 == "5"); true console.log(5 === "5"); false
Task: Compare 10 and "10" using == and ===.

4. Logical Operators

Used for multiple conditions.

&& AND

|| OR

! NOT

let age = 20; if(age > 18 && age < 30){ console.log("Young adult"); }
Task: Check if number is greater than 10 AND less than 50.

5. Unary Operators

Works with one value.

++ increase

-- decrease

let likes = 5; likes++; console.log(likes);
Task: Create a variable and increase it using ++.

6. Ternary Operator

Short version of if else.

let age = 17; let result = age >= 18 ? "Adult" : "Minor"; console.log(result);
Task: Check if marks are above 50 then pass otherwise fail.

7. If Statement

let age = 18; if(age >= 18){ console.log("You can vote"); }

8. If Else

let password = "1234"; if(password === "1234"){ console.log("Login successful"); } else{ console.log("Wrong password"); }

9. Else If

let marks = 75; if(marks >= 80){ console.log("A grade"); } else if(marks >= 60){ console.log("B grade"); } else{ console.log("C grade"); }

10. Switch Statement

let day = 2; switch(day){ case 1: console.log("Monday"); break; case 2: console.log("Tuesday"); break; default: console.log("Unknown day"); }
Task: Create switch for months.
