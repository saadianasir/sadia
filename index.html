1. let and const

Difference between var, let, and const

  • var → Function scoped and can be redeclared.
  • let → Block scoped and cannot be redeclared in same block.
  • const → Block scoped and value cannot be reassigned.

When to use let

Use let when the value of a variable may change later.

let age = 18;
age = 19;

Why const is important

const helps prevent accidental changes. It makes code safer and easier to understand.

const pi = 3.14;

2. Data Types (Basic)

  • String: Text values. Example: "Hello"
  • Number: Numeric values. Example: 25
  • Boolean: True or False values. Example: true
  • Undefined: Variable declared but no value assigned.
  • Null: Empty value assigned intentionally.
  • Using typeof: Used to check data type. Example: typeof "Hello"
